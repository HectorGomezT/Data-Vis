Slide, dashboard, celular o reporte

Antes de abrir Excel, contesta estas cuatro preguntas. Saber el espacio con el que cuentas es clave: un chart para una slide a pantalla completa no es el mismo que para un cuadrito de dashboard o para un celular. Lo vamos a ver en El dashboard, al final del partido.
